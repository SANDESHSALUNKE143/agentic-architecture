# Embedding Retrieval

Use exactly matching model identity, revision, dimensions, normalization, metric and preprocessing for index ingestion and query embeddings. Same dimensions alone do not establish compatibility. The generation model is independent. SDK checks finite, nonzero vectors and supports cosine/L2 profiles. Reindex to a new collection before changing embedding profiles. Enforce document ACLs in a trusted service; collection names and Context alone are not authentication.

## Review rule

Check the installed platform version and repository implementation map before applying these standards. Future components require implementation and tests, not only configuration.
