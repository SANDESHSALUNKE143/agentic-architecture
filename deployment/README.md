# Deployment

Use the [full local platform](full/README.md) for the complete local service path. The [AgentN-only path](local/README.md) remains a smaller alternative; do not run both on port 8010. See [release gates](../docs/release-gates.md) before remote or production deployment.


## Folder contents

Supported local profiles and operating runbooks.

- [full/](full/README.md): Ten-container local platform and monitoring profile.
- [local/](local/README.md): Smaller AgentN-only profile; shares port 8010 with full profile.
