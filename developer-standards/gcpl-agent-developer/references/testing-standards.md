# Testing Standards

Validate the manifest and runtime config, then run SDK contract/integration/compatibility tests and independent consumer tests. Cover scope denial before side effects, incompatible profiles, malformed tool actions, prerequisites, budget exhaustion, repeated calls, timeout, result size and metadata redaction. Evaluate groundedness, stale/missing data and domain arithmetic separately. Use synthetic fixtures; report mocks, in-process integrations, localhost checks and live certifications distinctly.

## Review rule

Check the installed platform version and repository implementation map before applying these standards. Future components require implementation and tests, not only configuration.
