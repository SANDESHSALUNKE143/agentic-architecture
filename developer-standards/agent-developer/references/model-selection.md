# Model Selection

Choose a model based on measured tool-action JSON compliance, grounding, latency, context length and cost. The demo model performs deterministic readiness, not arbitrary reasoning. The compatible adapter uses bounded chat completions and records usage; provider-specific parameter support needs live certification. No silent switch to a more expensive model. The current byte-based run reservation is a guard, not a durable financial ledger.

## Review rule

Check the installed platform version and repository implementation map before applying these standards. Future components require implementation and tests, not only configuration.
