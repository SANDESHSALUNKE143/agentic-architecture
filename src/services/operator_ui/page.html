Use the SDK from an agent repository

Install one SDK version. The agent owns its screen, instruction, database, and vector store. It passes an already-open connection into a port. The runner checks permissions, allowlists, and required evidence.

python -m pip install -e '/path/to/agentic-architecture[service]'

What the sample does

  1. Model.decide is the agent's decision. With no observations it asks for read_status. After that tool returns, it writes the answer. A real agent puts its own decision rules here.
  2. read_status is the agent's evidence. The SDK calls it only when this request's context includes the status:read permission.
  3. ToolSpec publishes the name, the description, the permission, and the argument schema. The model sees that description. It does not see credentials or a server URL.
  4. AgentRunner is the shared loop: decide, call the tool, decide again. required_before_final rejects an answer that skipped read_status.
  5. Context is this one call: tenant, agent id, and the grants. runner.run takes the question. The question is not written into the trace.

Smallest agent

This sample registers one tool and refuses a final answer until that tool has run. Replace the handler with the agent's own evidence.

from agentic_sdk.contracts import Context
from agentic_sdk.contracts.orchestration.types import ModelReply
from agentic_sdk.core.execution.tools import ToolRegistry, ToolSpec
from agentic_sdk.core.harness.runner import AgentRunner

class Model:
    async def decide(self, instruction, question, observations, tools, max_output_tokens):
        if not observations:
            return ModelReply("tool", {"type": "tool", "tool": "read_status", "arguments": {}}, 1, 1)
        return ModelReply("final", {"type": "final", "answer": "ready"}, 1, 1)

async def read_status(ctx, arguments):
    return {"status": "ready"}

tools = ToolRegistry()
tools.add(ToolSpec(
    "read_status",
    "Read the status this agent owns.",
    "status:read",
    {"type": "object", "properties": {}, "required": []},
    read_status,
))
runner = AgentRunner(
    Model(),
    tools,
    "Answer from the status tool.",
    required_before_final=frozenset({"read_status"}),
)
context = Context("tenant", "my-agent", frozenset({"agent:invoke", "status:read"}))
result = await runner.run(context, "Is it ready?")

Pass a connection the agent already opened

A table, a vector store, or a graph is the same shape. The agent opens the connection, chooses the allowlist, and keeps the password. sql.query checks the permission and the table name, then reads rows. Changing the database does not change AgentRunner.

async def query_rows(ctx, arguments):
    return sql.query(ctx, arguments["table"], arguments["limit"])
